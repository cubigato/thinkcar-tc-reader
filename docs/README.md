# Documentation

This directory contains all documentation for the ThinkCar TC Reader project.

## Main Documentation

- **[TC-FILE-FORMAT.md](TC-FILE-FORMAT.md)** - Complete specification of the ThinkCar .TC binary file format (reverse-engineered). This is the primary reference for understanding the file structure.

- **[IMPLEMENTATION.md](IMPLEMENTATION.md)** - Detailed implementation summary of the library, including architecture decisions, API design, and validation results.

- **[AGENTS.md](AGENTS.md)** - Development guidelines and architecture notes for AI agents and contributors working on this project.

## Archive

The `archive/` subdirectory contains historical documentation that has been superseded:

- **[archive/tc-file-info.md](archive/tc-file-info.md)** - Early research notes and speculation about the TC file format. This has been replaced by TC-FILE-FORMAT.md and can be safely ignored.
